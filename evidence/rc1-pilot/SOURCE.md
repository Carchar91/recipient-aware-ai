# Preserved earlier pilot, with its limitations

This is a selected public copy of the original synthetic rc.1 pilot: its report, structural results, two primary agent assessments, preregistration, unchanged blinded-review material and 20 original first responses with their prompts and inputs. All copied files are byte-identical to the original local records. No answer, failure or primary assessment was corrected. The original local pilot remains untouched.

**18 of 20 structural checks passed; the control was partially contaminated by a one-line operation description. No comparative advantage was established.** Independent human review was not performed. The report's recommendations and publication-status statements describe that historical stage, not the current release.

The original report refers to local runtime traces, host probes and configuration files that are not part of this selected public evidence copy. They have not been deleted or rewritten. Account/host configuration, unrelated runtime catalogues and the separately held blind-review key are not distributed here. The report's downloadable blinded-review ZIP is preserved exactly, including its original checksum.

The `first-responses/` directory preserves each original `response.json`, `prompt.txt` and `input.json`. These are synthetic evaluation records, not real client correspondence. The transparent development cases in the main package must not be described as held-out evidence. The later [eight rc.2 sessions](../rc2-eight-runs/REPORT_RU.md) are a separate stage and a separate set of answers.
