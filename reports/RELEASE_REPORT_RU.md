# Recipient-Aware AI: результат подготовки

**Версия: 0.1.0-rc.1. Локальная инженерная проверка: PASS.**

## Что сделано

Подготовлен отдельный проект из пяти самостоятельно вызываемых протоколов: Profiler, Profiler Plus, Dopamine Hooks, Reverse и Rail. Для каждого есть операционная спецификация, самостоятельный SKILL.md, схема ответа, пример и тестовые сценарии. Общие нравственные и доказательные ограничения включены в каждую переносимую инструкцию.

Реализованы компиляция воспроизводимых запросов с SHA-256, проверка JSON и ссылок на доказательства, вывод читабельного результата, отдельный адаптер OpenAI Responses, парные испытания baseline/protocol и подготовка материалов для слепой человеческой оценки. Автоматической отправки сообщений, доступа к аккаунтам или инструментов покупки/подачи документов нет.

## Фактические результаты

- 113 инженерных тестов выполнены: 0 ошибок, 0 провалов, 0 пропусков.
- 30 синтетических сценариев: по шесть на каждый режим.
- Пять корректных образцов проходят проверку структуры; пять намеренно ошибочных образцов отклоняются.
- Все пять генерируемых skills совпадают с исходными спецификациями. Автоматическое подключение остальных режимов не предусмотрено.
- Утверждённый английский источник сохранён побайтно. Новые схемы и тесты прямо обозначены как формализация для этого кандидата.
- Проверены запрет сетевых вызовов без согласия, отсутствие передачи ключа в отчёт, обработка ошибок API на моках, воспроизводимость ZIP и контроль целостности файлов.

Это результаты **программной проверки**, не 113 доказательств эффективности методологии.

## Что не выполнено и не заявляется

Реальные модельные вызовы не запускались: API-ключ в рабочей среде отсутствует, согласование платного эксперимента не проводилось. Независимой смысловой оценки нет. Примеры написаны при подготовке пакета и явно помечены как синтетические образцы.

Подключённый GitHub возвращает 404 для Carchar91/recipient-aware-ai. Это не позволяет отличить отсутствующий репозиторий от недоступного текущему подключению. Действий создания репозитория и GitHub Release в доступном коннекторе нет; авторизованного gh в текущей среде также нет. Поэтому реальный GitHub Release не создан. Пакет содержит рабочий сценарий для создания нового PRIVATE репозитория и DRAFT prerelease через авторизованный Кодекс. По умолчанию этот сценарий только показывает план.

Публичная лицензия не выбрана владельцем. Она не назначена автоматически. Плагин в каталоге не создавался. Сайт prudchenko.com и его репозиторий не изменялись.
