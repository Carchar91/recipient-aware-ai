# rc.2 — точечные исправления после содержательной приёмки

Выполнено `CODEX_RC2_TARGETED_FIXES_RU.md` из пользовательского `recipient-aware-ai-rc2-content-review.zip`. Рабочая копия создана из принятого архива rc.2 с SHA-256 `419e3875e39deec00eeb17abfebf4443b841da9e2e964cb55f53291b1bed4deb`. Новый контракт, режим или удалённая версия не создавались.

## Изменения

1. **Profiler:** в двух authored outputs исправлены main_barrier, связанные возможные возражения и рамка общения. Audit описывает только неполноту предоставленного краткого предложения; критерий воспроизводимости связан с прямо указанной ответственностью перед советом. Learning отделяет известные критерии адресата от неизвестных условий текущего предложения. В канонический протокол добавлено одно правило сохранения статуса факта, гипотезы или неизвестного в барьере и рамке; skill пересобран штатно. Sparse не изменён. Во входы новые факты не добавлялись.
2. **Dopamine Hooks:** отредактирован существующий authored output. Текст развивает мысль от неопределённого поручения к получателю, критерию завершения и полезности явного неизвестного. Все E1–E4, числа, пересечение групп, три поля и отсутствие испытаний сохранены. Число абзацев не является критерием PASS; добавлены человеческие вопросы обзора. Каноническая инструкция режима сохранена.
3. **Rail:** S2 убран только из recipient-facing message. Теперь прямо сказано не отправлять поставщикам запрос на точное количество до уточнения у Олега. Обычный renderer показывает ожидаемый результат заблокированного шага, причину и источник; ID и зависимости остаются в machine/audit. Разрешение на сбор информации, подготовленные материалы, расчёты, роли и технические зависимости не изменялись.
4. **Единый renderer:** собственные русские/английские подписи выбираются в `rai/core.py`. Генератор development-примеров вызывает этот же `render_output` без глобальных замен по готовому тексту. Цитаты, message/body, имена, существенные формулировки и фиксированный ethical_notice не переводятся. Поддержка всех языков не заявляется.
5. Добавлены пять регрессионных тестов. В существующей проверке порядка вывода Reverse английское имя служебного раздела заменено на русское; сама проверка порядка сохранена. Смысловые допущения Profiler оцениваются человеческими критериями, а не универсальным regex-детектором.
