# Recipient-Aware AI

Пять самостоятельных протоколов Евгения Прудченко, разработанных в практической работе с ИИ-помощником Seraphim.

Версия `0.1.0-rc.1`: локально проверенный кандидат для приватного репозитория. Это не опубликованный GitHub Release и не готовый плагин каталога.

Внутри: Профайлер, Профайлер Плюс, Дофаминовые хуки, Реверс и Rail. Для каждого подготовлены исполняемые инструкции, входной и выходной формат, пример и тестовые сценарии. Режимы не объединяются автоматически.

## Что можно проверить

Команда `python tools/verify.py` выполняет инженерные тесты. Команда `python -m rai compile --input examples/reverse/input.json` собирает воспроизводимую пару инструкций без обращения к модели. `validate-output` проверяет структуру, ссылки на факты, цитаты, сохранённые условия и ветвления. `render` показывает читабельный результат.

Подготовлены 30 синтетических сценариев, по шесть на каждый режим, и пять положительных и пять намеренно ошибочных образцов. Примеры написаны при подготовке пакета, а не получены в независимом эксперименте.

Для реальных модельных испытаний есть отдельный адаптер OpenAI Responses и парное сравнение обычной инструкции с протоколом. Оплачиваемые вызовы требуют явных флагов согласия и API-ключа. В текущей подготовке такие вызовы не выполнялись.

Локальный PASS не означает доказанную эффективность или невозможность злоупотребления. Смысловая оценка человеком и проверка реальных ответов модели остаются отдельными этапами.
