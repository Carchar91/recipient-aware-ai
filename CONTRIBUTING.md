# Contributing

This is a private candidate until the owner approves public release and licensing. Do not infer a public contribution license from this file.

Propose one scoped change with a reason and test. Preserve source terminology and trace substantive changes to SOURCE_MAP.md. Do not merge five modes into an automatic pipeline. Add synthetic cases for regressions, including benign counterexamples when adding a refusal rule.

Edit protocols/*.md and schemas, then run `python tools/build_skills.py` and `python tools/verify.py`. Report whether results are fixture tests, live provider runs, author review or independent review. Do not claim effects from self-authored examples.

All test data must be synthetic or explicitly cleared and safely redacted. No website edits, deployment actions, real message sending, license changes, visibility changes or releases without separate owner authorization.
